# OpenKart Divergences Log

Every behavioral or architectural divergence from pinned upstream **SuperTuxKart `1.5`** (`supertuxkart/stk-code`, commit `1fb491f507216c5d181ccd85f29ff08eca003827`) is recorded here with its cause (`engine limit`, `platform policy`, or `ToS`).

---

## Accepted Architectural Divergences (`AGENTS.md`)

| Area | Upstream STK `1.5` | OpenKart Behavior | Cause |
|---|---|---|---|
| **Vehicle Physics Solver** | Bullet Physics (`lib/bullet` + `src/physics/btKart.cpp`) raycast vehicle with bilateral zero-slip tire constraint (`<friction slip="10000000"/>`) and colliding `btCompoundShape` chassis rigid body + contact manifold. | Pure-Luau 120 Hz fixed-step rigid-body + 4-wheel raycast solver ([physics-spec.md](physics-spec.md)) with Pacejka slip-angle → grip curve; **Bullet contact-manifold & swept CCD replaced by unified resting-contact manifold (wheel bottom-out + static `GetPartBoundsInBox` overlap recovery + 6-axis shrunk-core probes + post-rotation overlap guard) and swept `Workspace:Blockcast` via `WorldQuery` with normal velocity projection** (measurable delta TBD against STK `1.5` reference telemetry). | **Engine limit** — C++/Bullet native runtime cannot execute on Roblox; deterministic Luau solver also required for exact state-reset + input-replay reconciliation. |
| **Networking & Synchronization** | ENet peer-to-peer / LAN host with global `RewindManager` state rollbacks (`src/network/`). | Server-authoritative Roblox match loop (`8–20` players) over `RemoteEvent` / `UnreliableRemoteEvent` with client-side input prediction/reconciliation and remote interpolation. | **Engine limit / platform policy** — Roblox controls transport, sockets, and server-client trust boundaries. |
| **Track & Kart Addons** | Runtime dynamic download & mounting of `.zip` addon packs (`src/addons/`). | Offline-converted curated packs built into the place via `tools/stk2rbx` and audited per-file in [CREDITS.md](../assets/CREDITS.md). | **Platform policy** — Roblox prohibits arbitrary dynamic code/asset loading at runtime. |

Safe to ignore as non-OpenKart Studio console noise; revisit if observed in a published blank place test. |
| **Nitro VFX Placeholder** | Upstream STK emits particle XMLs (`nitro.xml`, `nitro-smoke.xml`) + `m_nitro_light` (`src/karts/kart_gfx.cpp:L55-L67, L101-L115`) via STK's attachment/kart-GFX system (`src/attachments/`, `src/karts/kart_gfx.cpp`). Replace with faithful ported STK particle/attachment presentation when `src/karts/kart_gfx.cpp` & `src/attachments/` land. |
| **Resting-Contact Restitution Threshold (`restContactBounceVel = 2.0 m/s`)** | OpenKart uses STK's exact speed-dependent piecewise-linear wall restitution curve (`0:1.0, 5:1.0, 20:0.2`, `data/stk_config.xml:L480`, `src/karts/kart.cpp:L1454`). In Bullet (`lib/bullet/src/BulletDynamics/ConstraintSolver/btContactSolverInfo.h:L82`), `m_restingContactRestitutionThreshold = 2` suppresses bounce on persistent resting contacts by contact lifetime in ticks. | **Engine limit / solver design** — OpenKart's stateless swept/overlap manifold does not persist contact-point lifetimes across ticks, so it suppresses bounce for normal impact speeds `< 2.0 m/s` (`KartTuning.collision.restContactBounceVel`) to prevent wall chatter while preserving STK restitution on dynamic impacts. |
| **Static Kart Mesh First Pass (Driver/Steering Animation Omitted)** | Upstream `stk-assets/karts/tux/tux.spm` is a skinned `SPMA` mesh (`16` bones, `60` keyframes over frames `0..613`, `m_bind_frame = 20`) driven by `KartModel::update` (`src/karts/kart_model.cpp`) for steering lean (`0..20..40`), win/lose/jump cycles, and bone-attached accessories (`headlight.spm`, `hat`). OpenKart's first-pass kart emitter (`tools/stk2rbx/kart_emit.py`) exports only the static pre-computed straight-pose (`frame 20`) `Body` + `Driver` `.glb` meshes plus 4 separate rigid wheel meshes (`WheelFrontLeft/Right`, `WheelRearLeft/Right`). | **Engine limit / phased pipeline** — Roblox requires a glTF/FBX skinned `Bone` + `AnimationClip` export pipeline (or runtime joint transforms) rather than STK's `SPMA` binary format. Skeletal driver/steering lean and night-only `headlight.spm` (external un-audited textures) are omitted in the first pass and deferred until rigged `.glb` export and `src/client/kart/KartPresentation.lua` land. |
